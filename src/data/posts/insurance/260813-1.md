# 실손의료보험(실비보험)이란? 국민 보험의 정체

"실비 있으세요?"

병원에서 접수할 때 한 번쯤 들어보셨을 질문입니다.

여기서 말하는 실비, 정식 명칭은 **실손의료보험**입니다.

---

## 1. 실손의료보험은 '실제 쓴 병원비'를 보장합니다

실손의료보험은 질병이나 상해로 병원 치료를 받을 때,

**내가 실제로 부담한 병원비의 일부를 돌려주는 보험**입니다.

예를 들어 병원비로 10만 원을 냈다면, 그중 일부를 실비보험에서

돌려받는 구조입니다.

$$
\text{실제 병원비} - \text{자기부담금} = \text{보험금}
$$

---

## 2. 병원비는 두 가지로 나뉩니다

| 구분   | 의미                                   |
| ------ | ---------------------------------------- |
| 급여   | 건강보험이 적용되는 항목               |
| 비급여 | 건강보험이 적용되지 않는 항목(도수치료 등) |

실손보험은 이 두 항목 모두에 대해 자기부담금을 제외한 나머지를

보상해 줍니다.

---

## 3. 가입 시기에 따라 세대가 다릅니다

실손보험은 언제 가입했느냐에 따라 세대가 나뉘고,

세대마다 보험료와 자기부담금 수준이 다릅니다.

| 세대 | 가입 시기          | 특징                          |
| ---- | -------------------- | ------------------------------- |
| 1세대 | ~2009년 9월          | 자기부담금 없음, 보험료 비쌈  |
| 2세대 | ~2017년 3월          | 자기부담금 낮음                |
| 3세대 | ~2021년 6월          | 특약 분리, 자기부담률 상승    |
| 4세대 | ~2026년 4월          | 보험료 저렴, 비급여 이용 시 할증 |
| 5세대 | 2026년 5월~          | 보험료 더 저렴, 자기부담률 더 높음 |

오래된 세대일수록 보험료는 비싸지만 보장이 넓고,

최근 세대일수록 보험료는 저렴하지만 자기부담금이 높습니다.

## 4. 실손보험은 중복 가입해도 소용없습니다

실손보험은 **실제로 쓴 병원비만큼만** 보상하기 때문에,

여러 개를 가입해도 병원비 이상으로 받을 수는 없습니다.

오히려 보험료만 이중으로 나가는 셈이므로, 한 개만 유지하는 것이

일반적으로 유리합니다.

---

## 한눈에 정리해 보겠습니다

| 용어         | 의미                                       |
| ------------ | -------------------------------------------- |
| 실손의료보험 | 실제 부담한 병원비 일부를 돌려주는 보험     |
| 급여/비급여  | 건강보험 적용 여부에 따른 병원비 구분       |
| 세대         | 가입 시기에 따른 실손보험 구분(1~5세대)     |
| 중복가입     | 병원비 이상으로 받을 수 없어 실익이 없음    |

---

## 마무리

실손보험은 **"국민 대부분이 가입한 필수 보험"**이라 불릴 만큼

흔한 보험이지만, 세대별 차이는 생각보다 큽니다.

내가 가입한 실손보험이 몇 세대인지 한 번 확인해 보시는 것을

추천드립니다.
