# 종신보험이란? 평생 보장의 의미

"가장의 든든한 보험"이라는 말과 함께 자주 등장하는 상품이 있습니다.

바로 **종신보험**입니다.

---

## 1. 종신보험은 '평생 보장'하는 사망보험입니다

종신보험은 이름 그대로 **가입자가 언제 사망하든 관계없이**

**사망보험금을 지급**하는 보험입니다.

$$
\text{사망 시점} = \text{언제든} \quad \Rightarrow \quad \text{보험금 지급}
$$

가입자가 90세에 사망하든, 100세에 사망하든 보장 기간의

제한이 없다는 점이 핵심입니다.

---

## 2. 정기보험과 무엇이 다를까요?

| 구분     | 종신보험           | 정기보험             |
| -------- | -------------------- | ---------------------- |
| 보장 기간 | 평생(종신)           | 정해진 기간(예: 80세까지) |
| 보험료   | 상대적으로 비쌈       | 상대적으로 저렴          |
| 목적     | 사망보험금 + 자산 이전 | 순수 사망 보장          |

정기보험은 정해진 기간 안에 사망해야 보험금이 나오지만,

종신보험은 언제 사망하더라도 반드시 지급된다는 차이가 있습니다.

---

## 3. 왜 종신보험에 가입할까요?

가장 흔한 목적은 **남겨진 가족의 생활비 보장**입니다.

가장이 갑자기 사망하더라도, 종신보험금으로 남은 가족의

생활비나 자녀 교육비를 마련할 수 있습니다.

또한 **상속세 재원 마련** 목적으로도 많이 활용됩니다.

---

## 4. 예시로 이해해 보겠습니다

사망보험금 1억 원짜리 종신보험에 가입했다고 가정해 보겠습니다.

| 사망 시점 | 보험금 지급 여부 |
| --------- | ------------------ |
| 가입 후 5년 | 지급               |
| 가입 후 30년 | 지급              |
| 가입 후 60년 | 지급              |

**어느 시점에 사망하더라도** 1억 원이 지급됩니다.

이 점이 정기보험과 가장 크게 다른 부분입니다.

## 한눈에 정리해 보겠습니다

| 용어     | 의미                                 |
| -------- | -------------------------------------- |
| 종신보험 | 사망 시점과 관계없이 평생 보장하는 보험 |
| 정기보험 | 정해진 기간 안에서만 보장하는 보험     |
| 사망보험금 | 피보험자 사망 시 수익자에게 지급되는 금액 |

---

## 마무리

종신보험은 보험료가 비싼 편이지만, **"언제 죽어도 반드시 지급된다"**는

확실성이 가장 큰 특징입니다.

내 상황에 평생 보장이 꼭 필요한지, 아니면 일정 기간만 필요한지를

먼저 고민해 보시는 것이 좋습니다.
