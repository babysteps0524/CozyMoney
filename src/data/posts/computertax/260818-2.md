# 전산세무 2급 원가회계 완벽 정리: 시험에 자주 나오는 핵심 개념과 계산 문제

전산세무 2급 시험을 준비하다 보면 **원가회계**에서 어려움을 느끼는 경우가 많습니다.

재무회계와 달리 원가회계는 단순히 분개를 외우는 것뿐만 아니라 **원가를 계산하고 제조과정을 이해하는 능력**이 필요하기 때문입니다.

특히 전산세무 2급에서는 원가회계의 모든 내용을 깊게 다루기보다는 **원가의 기본 개념, 원가의 구성, 제조원가 계산, 제조원가명세서, 손익 계산** 등 기본적인 계산과 개념을 정확하게 이해하는 것이 중요합니다.

이번 글에서는 전산세무 2급 시험을 준비하는 사람을 위해 원가회계의 핵심 내용을 처음부터 차근차근 정리해 보겠습니다.

---

## 1. 원가회계란 무엇일까요?

원가회계는 기업이 제품이나 서비스를 생산하는 과정에서 발생한 **원가를 계산하고 관리하기 위한 회계**입니다.

예를 들어 어떤 회사가 책상을 제조한다고 생각해 보겠습니다.

책상을 만들기 위해서는 다음과 같은 비용이 발생할 수 있습니다.

- 나무 구입비
- 나사와 부품 구입비
- 제품을 만드는 직원의 급여
- 공장 전기요금
- 공장 임차료
- 기계 감가상각비

이러한 비용을 제품 생산과 관련하여 체계적으로 계산하는 것이 원가회계입니다.

쉽게 말하면,

> **원가회계 = 제품을 만드는 데 얼마가 들었는지를 계산하는 회계**

라고 이해하면 됩니다.

## 2. 원가와 비용은 같은 것일까요?

원가회계를 공부할 때 가장 먼저 구분해야 하는 것이 **원가와 비용**입니다.

두 단어가 비슷하게 사용되지만 회계에서는 구분할 필요가 있습니다.

### 원가

특정 제품이나 서비스를 생산하기 위해 소비된 경제적 가치입니다.

예를 들어 제품을 생산하기 위해 원재료를 사용했다면 해당 원재료의 소비액은 제조원가에 포함될 수 있습니다.

### 비용

기업의 수익을 창출하기 위해 당기에 소비된 경제적 가치입니다.

판매와 관리 활동에서 발생하는 판매비와 관리비 등이 대표적인 예입니다.

예를 들어 제조업체에서 발생한 광고선전비는 일반적으로 제품 제조원가가 아니라 **판매비와관리비**로 처리합니다.

---

## 3. 제조기업의 원가를 이해해야 합니다

원가회계에서 중요한 것은 **제조기업의 생산 과정**입니다.

제조기업은 원재료를 구입하여 제품을 만들고, 완성된 제품을 판매합니다.

전체 과정을 단순화하면 다음과 같습니다.

```text
원재료
   ↓
생산과정
   ↓
재공품
   ↓
완제품
   ↓
제품 판매
```

이 과정에서 발생하는 원가를 계산해야 합니다.

예를 들어 원재료를 구입했다고 해서 그 금액 전체가 바로 당기의 제조원가가 되는 것은 아닙니다.

실제로 생산에 사용된 원재료가 얼마인지 계산해야 합니다.

---

# 4. 제조원가의 3요소

전산세무 2급 원가회계에서 가장 중요한 내용 중 하나가 **제조원가의 3요소**입니다.

제조원가는 크게 다음 세 가지로 구성됩니다.

| 구분         | 의미                                                          | 예시                                     |
| ------------ | ------------------------------------------------------------- | ---------------------------------------- |
| 직접재료비   | 제품 생산에 직접 사용된 재료비                                | 제품의 원재료                            |
| 직접노무비   | 제품 생산에 직접 투입된 근로자의 임금                         | 생산직 직원 급여                         |
| 제조간접비   | 제조과정에서 발생하지만 특정 제품에 직접 추적하기 어려운 원가 | 공장 전기료, 공장 임차료                 |
| **제조원가** | **위 세 가지 원가의 합계**                                    | **직접재료비 + 직접노무비 + 제조간접비** |

따라서 기본 공식은 다음과 같습니다.

**제조원가 = 직접재료비 + 직접노무비 + 제조간접비**

이 공식은 원가회계 문제를 풀 때 계속 등장하기 때문에 정확하게 기억해야 합니다.

---

# 5. 직접원가와 간접원가

원가를 이해하기 위해서는 **직접원가와 간접원가**의 차이도 알아야 합니다.

## 직접원가

특정 제품에 직접적으로 추적할 수 있는 원가입니다.

예를 들어 책상 하나를 만드는 데 사용된 특정 목재의 사용량과 금액을 정확하게 측정할 수 있다면 직접재료비로 분류할 수 있습니다.

## 간접원가

특정 제품 하나에 직접적으로 추적하기 어려운 원가입니다.

예를 들어 공장에서 여러 제품을 생산하는 경우 공장 전체의 전기료를 특정 제품 하나에 직접 연결하기 어렵습니다.

이러한 비용은 제조간접비로 처리합니다.

| 구분          | 직접원가                   | 간접원가                         |
| ------------- | -------------------------- | -------------------------------- |
| 의미          | 특정 제품에 직접 추적 가능 | 특정 제품에 직접 추적하기 어려움 |
| 대표적인 예   | 직접재료비                 | 제조간접비                       |
| 제품과의 관계 | 직접적                     | 간접적                           |
| 배부 필요성   | 일반적으로 낮음            | 배부가 필요할 수 있음            |

---

# 6. 직접재료비란 무엇일까요?

직접재료비는 제품을 생산하는 데 직접 사용되는 재료의 원가입니다.

예를 들어 가구 제조업체에서 책상을 만든다고 하겠습니다.

책상의 상판과 다리 등에 사용되는 목재가 제품에 직접 사용된다면 해당 목재의 소비액은 직접재료비가 될 수 있습니다.

중요한 것은 **재료를 구입한 금액과 실제 사용한 금액은 다를 수 있다는 것**입니다.

---

## 7. 재료비 계산

원재료를 일정 기간 동안 구입했다고 해서 구입액 전체가 당기의 재료비가 되는 것은 아닙니다.

기초에 가지고 있던 원재료와 당기에 구입한 원재료를 합한 뒤 기말에 남은 원재료를 차감하면 실제 사용된 재료비를 계산할 수 있습니다.

공식은 다음과 같습니다.

**재료비 = 기초원재료 + 당기원재료매입액 - 기말원재료**

예를 들어 다음과 같은 자료가 있다고 해보겠습니다.

| 항목               |        금액 |
| ------------------ | ----------: |
| 기초원재료         | 1,000,000원 |
| 당기 원재료 매입액 | 5,000,000원 |
| 기말원재료         | 1,500,000원 |

재료비는 다음과 같이 계산합니다.

**1,000,000 + 5,000,000 - 1,500,000 = 4,500,000원**

따라서 당기에 실제 사용된 원재료는 **4,500,000원**입니다.

---

# 8. 직접노무비란 무엇일까요?

직접노무비는 제품을 직접 생산하는 근로자에게 지급하는 임금입니다.

예를 들어 자동차 제조공장에서 자동차를 직접 조립하는 생산직 근로자의 임금은 직접노무비가 될 수 있습니다.

반면 생산과 직접적인 관련이 없는 관리부서 직원의 급여는 제조원가에 포함되는 직접노무비가 아닙니다.

### 예시

| 직원               | 급여의 일반적인 분류    |
| ------------------ | ----------------------- |
| 제품 생산 직원     | 직접노무비              |
| 생산라인 작업자    | 직접노무비              |
| 공장 관리 직원     | 제조간접비가 될 수 있음 |
| 본사 경영지원 직원 | 판매비와관리비          |
| 영업사원           | 판매비와관리비          |

다만 실제 회계처리는 기업의 원가계산 기준과 업무 내용 등에 따라 달라질 수 있으므로 **업무의 성격과 제조활동과의 관련성**을 기준으로 판단해야 합니다.

---

# 9. 제조간접비란 무엇일까요?

제조간접비는 제조과정에서 발생하지만 특정 제품에 직접적으로 추적하기 어려운 원가입니다.

대표적인 예는 다음과 같습니다.

- 공장 전기료
- 공장 수도료
- 공장 임차료
- 공장 건물 감가상각비
- 생산설비 감가상각비
- 공장 소모품비
- 공장 관리자의 급여

예를 들어 공장에서 A제품과 B제품을 동시에 생산한다고 가정해 보겠습니다.

공장의 전기료가 1,000,000원 발생했습니다.

이 전기료를 A제품에서 정확히 얼마가 발생했고 B제품에서 정확히 얼마가 발생했는지 직접 측정하기 어렵다면 제조간접비로 분류할 수 있습니다.

---

# 10. 제조원가를 계산하는 방법

이제 제조원가의 전체 구조를 살펴보겠습니다.

제조원가는 다음과 같이 계산합니다.

```text
직접재료비
      +
직접노무비
      +
제조간접비
      ↓
   제조원가
```

예를 들어 다음과 같은 자료가 있다고 하겠습니다.

| 항목       |        금액 |
| ---------- | ----------: |
| 직접재료비 | 3,000,000원 |
| 직접노무비 | 2,000,000원 |
| 제조간접비 | 1,000,000원 |

제조원가는 다음과 같습니다.

**3,000,000 + 2,000,000 + 1,000,000 = 6,000,000원**

따라서 제조원가는 **6,000,000원**입니다.

# 11. 제조원가명세서란 무엇일까요?

전산세무 2급에서 원가회계를 공부할 때 반드시 이해해야 하는 것이 **제조원가명세서**입니다.

제조원가명세서는 일정 기간 동안 제품을 제조하기 위해 발생한 원가를 계산하여 보여주는 명세서입니다.

기본적인 구조는 다음과 같습니다.

| 구분               |    금액 |
| ------------------ | ------: |
| 직접재료비         |     XXX |
| 직접노무비         |     XXX |
| 제조간접비         |     XXX |
| **당기총제조원가** | **XXX** |

여기서 중요한 것은 **당기총제조원가**입니다.

당기총제조원가는 일정 기간 동안 제조활동에서 발생한 제조원가의 총액입니다.

---

# 12. 재공품이 중요한 이유

제품을 생산하다 보면 회계기간이 끝났을 때 아직 완성되지 않은 제품이 있을 수 있습니다.

이를 **재공품**이라고 합니다.

예를 들어 12월 31일 현재 제품을 만들고 있지만 아직 완성되지 않았다면 해당 제품에 투입된 원가는 재공품으로 남아 있을 수 있습니다.

따라서 제조원가를 계산할 때는 기초재공품과 기말재공품을 고려해야 합니다.

---

# 13. 당기제품제조원가 계산

당기제품제조원가는 다음과 같이 계산합니다.

**당기제품제조원가 = 기초재공품 + 당기총제조원가 - 기말재공품**

이 공식은 전산세무 2급 시험에서 매우 중요한 계산 공식입니다.

예를 들어 다음과 같은 자료가 있다고 하겠습니다.

| 항목           |        금액 |
| -------------- | ----------: |
| 기초재공품     |   500,000원 |
| 당기총제조원가 | 6,000,000원 |
| 기말재공품     |   700,000원 |

당기제품제조원가는 다음과 같습니다.

**500,000 + 6,000,000 - 700,000 = 5,800,000원**

따라서 당기제품제조원가는 **5,800,000원**입니다.

---

# 14. 완성된 제품과 판매된 제품은 다릅니다

원가회계를 처음 공부할 때 자주 혼동하는 부분입니다.

제품을 완성했다고 해서 바로 판매된 것은 아닙니다.

제조기업의 흐름은 다음과 같습니다.

```text
원재료
  ↓
재공품
  ↓
완제품
  ↓
판매
```

따라서 제품이 완성된 후에도 일부 제품은 창고에 남아 있을 수 있습니다.

이러한 제품은 **제품재고**로 남습니다.

---

# 15. 매출원가 계산

제품을 판매하면 판매된 제품에 해당하는 원가를 **매출원가**라고 합니다.

매출원가는 다음과 같이 계산할 수 있습니다.

**매출원가 = 기초제품 + 당기제품제조원가 - 기말제품**

예를 들어 다음과 같은 자료가 있다고 하겠습니다.

| 항목             |        금액 |
| ---------------- | ----------: |
| 기초제품         | 1,000,000원 |
| 당기제품제조원가 | 5,800,000원 |
| 기말제품         | 1,300,000원 |

매출원가는 다음과 같습니다.

**1,000,000 + 5,800,000 - 1,300,000 = 5,500,000원**

따라서 매출원가는 **5,500,000원**입니다.

---

# 16. 원가의 전체 흐름을 한 번에 이해하기

지금까지 배운 내용을 연결하면 다음과 같습니다.

![제조기업의 원가 흐름](img_cost_flow.svg)

```text
원재료
   ↓
직접재료비
   +
직접노무비
   +
제조간접비
   ↓
당기총제조원가
   ↓
기초재공품 + 당기총제조원가 - 기말재공품
   ↓
당기제품제조원가
   ↓
기초제품 + 당기제품제조원가 - 기말제품
   ↓
매출원가
```

이 흐름을 이해하면 원가회계 계산문제를 훨씬 쉽게 풀 수 있습니다.

# 17. 원가회계 핵심 계산 공식

시험 전에 다음 공식을 정리해 두는 것이 좋습니다.

| 계산 대상        | 공식                                     |
| ---------------- | ---------------------------------------- |
| 재료비           | 기초원재료 + 당기매입액 - 기말원재료     |
| 제조원가         | 직접재료비 + 직접노무비 + 제조간접비     |
| 당기제품제조원가 | 기초재공품 + 당기총제조원가 - 기말재공품 |
| 매출원가         | 기초제품 + 당기제품제조원가 - 기말제품   |

이 네 가지 공식을 연결해서 이해하는 것이 중요합니다.

---

# 18. 종합 계산문제를 풀어보겠습니다

다음과 같은 자료가 있다고 가정해 보겠습니다.

| 항목             |        금액 |
| ---------------- | ----------: |
| 기초원재료       | 1,000,000원 |
| 당기 원재료 매입 | 5,000,000원 |
| 기말원재료       | 1,500,000원 |
| 직접노무비       | 2,000,000원 |
| 제조간접비       | 1,000,000원 |
| 기초재공품       |   500,000원 |
| 기말재공품       |   700,000원 |
| 기초제품         | 1,000,000원 |
| 기말제품         | 1,300,000원 |

먼저 재료비를 계산합니다.

**1,000,000 + 5,000,000 - 1,500,000 = 4,500,000원**

따라서 직접재료비를 4,500,000원이라고 하면,

**당기총제조원가**

= 직접재료비 + 직접노무비 + 제조간접비

= 4,500,000 + 2,000,000 + 1,000,000

= **7,500,000원**

다음으로 당기제품제조원가를 계산합니다.

**기초재공품 + 당기총제조원가 - 기말재공품**

= 500,000 + 7,500,000 - 700,000

= **7,300,000원**

마지막으로 매출원가를 계산합니다.

**기초제품 + 당기제품제조원가 - 기말제품**

= 1,000,000 + 7,300,000 - 1,300,000

= **7,000,000원**

따라서 최종적으로 매출원가는 **7,000,000원**입니다.

# 19. 제조원가와 판매비와관리비를 구분해야 합니다

시험에서는 제조원가에 포함되는 항목과 판매비와관리비에 포함되는 항목을 구분하는 문제가 나올 수 있습니다.

| 항목                 | 일반적인 분류  |
| -------------------- | -------------- |
| 제품 생산용 원재료   | 제조원가       |
| 생산직 근로자 임금   | 제조원가       |
| 공장 전기료          | 제조원가       |
| 공장 임차료          | 제조원가       |
| 공장 기계 감가상각비 | 제조원가       |
| 본사 직원 급여       | 판매비와관리비 |
| 영업사원 급여        | 판매비와관리비 |
| 광고선전비           | 판매비와관리비 |
| 본사 임차료          | 판매비와관리비 |
| 판매수수료           | 판매비와관리비 |

핵심은 **제조활동과 관련된 비용인지**를 판단하는 것입니다.

# 20. 제조원가에 포함되는 비용과 포함되지 않는 비용

다음과 같이 정리하면 이해하기 쉽습니다.

```text
                 제조활동
                    │
          ┌─────────┴─────────┐
          ↓                   ↓
      제조 관련             비제조 관련
          │                   │
          ↓                   ↓
      제조원가            판매비와관리비
          │                   │
          ├─ 직접재료비       ├─ 광고선전비
          ├─ 직접노무비       ├─ 판매직 급여
          └─ 제조간접비       └─ 본사 관리비
```

따라서 단순히 "급여" 또는 "전기료"라는 이름만 보고 판단하면 안 됩니다.

**어디에서 어떤 목적으로 발생한 비용인지**를 확인해야 합니다.

# 21. 원가의 형태에 따른 분류

원가는 여러 가지 기준으로 분류할 수 있습니다.

대표적으로 **재료비, 노무비, 경비**로 구분할 수 있습니다.

| 원가 요소 | 의미                            | 예시               |
| --------- | ------------------------------- | ------------------ |
| 재료비    | 재료 소비에 따른 원가           | 원재료             |
| 노무비    | 근로 제공에 따른 원가           | 생산직 급여        |
| 경비      | 재료비와 노무비 이외의 제조원가 | 전기료, 감가상각비 |

이를 다시 제품과의 추적 가능성에 따라 직접원가와 간접원가로 나눌 수 있습니다.

---

# 22. 원가 3요소와 직접·간접원가를 함께 이해하기

두 가지 분류 기준을 함께 보면 다음과 같습니다.

| 구분   | 직접비     | 간접비     |
| ------ | ---------- | ---------- |
| 재료비 | 직접재료비 | 간접재료비 |
| 노무비 | 직접노무비 | 간접노무비 |
| 경비   | 직접경비   | 간접경비   |

이 가운데 제조간접비에는 일반적으로 **간접재료비, 간접노무비, 간접경비** 등이 포함될 수 있습니다.

따라서 제조원가를 단순하게 보면 다음과 같은 구조가 됩니다.

**제조원가 = 직접재료비 + 직접노무비 + 제조간접비**

---

# 23. 원가회계에서 재고자산의 흐름

원가회계를 이해하기 위해서는 재고자산의 흐름을 이해하는 것이 중요합니다.

제조기업에서는 일반적으로 다음과 같은 재고자산이 등장합니다.

| 재고자산 | 의미                                  |
| -------- | ------------------------------------- |
| 원재료   | 아직 생산에 투입하지 않은 재료        |
| 재공품   | 생산 중이지만 아직 완성되지 않은 제품 |
| 제품     | 생산이 완료된 제품                    |

각각의 흐름은 다음과 같습니다.

```text
원재료
  ↓
생산에 투입
  ↓
재공품
  ↓
생산 완료
  ↓
제품
  ↓
판매
```

이 흐름을 정확하게 이해하면 재고자산 관련 계산문제도 쉽게 접근할 수 있습니다.

---

# 24. 기초재고와 기말재고를 차감하는 이유

원가 계산에서 자주 등장하는 공식이 있습니다.

**기초재고 + 당기 발생액 - 기말재고**

왜 기말재고를 빼는 것일까요?

기말에 남아 있는 재고는 아직 당기에 판매되거나 소비되지 않은 부분이기 때문입니다.

예를 들어 원재료를 1,000만 원어치 보유하고 있었는데 그중 300만 원어치가 기말에 남아 있다면 실제 생산에 사용된 금액은 700만 원입니다.

따라서,

**1,000만 원 - 300만 원 = 700만 원**

이 됩니다.

이 원리는 원재료뿐만 아니라 재공품과 제품의 계산에서도 반복적으로 사용됩니다.

---

# 25. 원가회계 시험에서 자주 혼동하는 부분

### ① 원재료 매입액과 재료비는 다릅니다

원재료 매입액은 당기에 구입한 금액입니다.

재료비는 실제 생산에 사용된 재료의 원가입니다.

따라서 기초원재료와 기말원재료를 함께 고려해야 합니다.

---

### ② 당기총제조원가와 당기제품제조원가는 다릅니다

당기총제조원가는 당기에 발생한 제조원가입니다.

당기제품제조원가는 여기에 기초재공품과 기말재공품을 반영한 금액입니다.

**당기제품제조원가 = 기초재공품 + 당기총제조원가 - 기말재공품**

---

### ③ 당기제품제조원가와 매출원가도 다릅니다

당기제품제조원가는 당기에 완성된 제품의 제조원가입니다.

하지만 완성된 제품이 모두 판매되는 것은 아닙니다.

따라서 기초제품과 기말제품을 고려해야 매출원가를 계산할 수 있습니다.

**매출원가 = 기초제품 + 당기제품제조원가 - 기말제품**

---

# 27. 원가회계 계산문제 풀이 순서

원가회계 계산문제를 만났을 때는 숫자부터 계산하기보다 **원가의 흐름을 먼저 확인하는 것**이 중요합니다.

다음 순서로 접근하면 됩니다.

```text
① 원재료 관련 자료 확인
          ↓
② 실제 재료비 계산
          ↓
③ 직접노무비 확인
          ↓
④ 제조간접비 확인
          ↓
⑤ 당기총제조원가 계산
          ↓
⑥ 재공품 반영
          ↓
⑦ 당기제품제조원가 계산
          ↓
⑧ 제품재고 반영
          ↓
⑨ 매출원가 계산
```

특히 문제에서 **기초와 기말 재고**가 제시되어 있다면 해당 재고가 원재료인지, 재공품인지, 제품인지 구분해야 합니다.

# 28. 원가회계 문제를 풀 때 기억해야 할 핵심

원가회계는 공식을 각각 따로 외우는 것보다 **하나의 흐름으로 이해하는 것이 중요합니다.**

가장 기본적인 흐름은 다음과 같습니다.

> **원재료 → 재공품 → 제품 → 매출원가**

그리고 각 단계에서 기초재고와 기말재고를 고려합니다.

### 원재료 단계

**기초원재료 + 당기매입 - 기말원재료 = 재료비**

### 재공품 단계

**기초재공품 + 당기총제조원가 - 기말재공품 = 당기제품제조원가**

### 제품 단계

**기초제품 + 당기제품제조원가 - 기말제품 = 매출원가**

이 세 단계의 연결 관계를 이해하면 원가회계 계산문제의 구조를 파악하기 쉬워집니다.

# 마무리

전산세무 2급의 원가회계는 처음에는 용어가 많고 계산 과정도 복잡해 보일 수 있습니다.

하지만 핵심적인 흐름은 생각보다 단순합니다.

**원재료가 생산에 투입되고 → 재공품이 되고 → 제품으로 완성되고 → 판매된 제품의 원가가 매출원가가 됩니다.**

그리고 각 단계에서 **기초재고를 더하고 기말재고를 빼는 구조**를 이해하면 대부분의 기본적인 원가 계산 문제를 체계적으로 접근할 수 있습니다.

특히 다음 네 가지는 반드시 구분해야 합니다.

> **재료비**

> **당기총제조원가**

> **당기제품제조원가**

> **매출원가**

최종적으로 다음 공식의 연결 관계를 정확하게 이해하는 것이 전산세무 2급 원가회계의 핵심입니다.

**재료비 = 기초원재료 + 당기매입액 - 기말원재료**

**당기총제조원가 = 직접재료비 + 직접노무비 + 제조간접비**

**당기제품제조원가 = 기초재공품 + 당기총제조원가 - 기말재공품**

**매출원가 = 기초제품 + 당기제품제조원가 - 기말제품**

원가회계는 단순 암기보다는 **원재료 → 재공품 → 제품 → 매출원가라는 원가의 흐름**을 중심으로 공부하면 훨씬 쉽게 이해할 수 있습니다.

원가회계의 핵심은 원재료·재공품·제품의 흐름과 각 단계의 재고 조정을 연결하는 데 있으므로, 기초·기말 재고가 섞인 종합 계산문제를 단계별 풀이와 함께 정리하면 계산 실수를 줄이고 시험 적용력을 높일 수 있습니다.
