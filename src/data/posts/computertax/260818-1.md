# 전산세무 2급 시험과목·시험시간·합격기준 완벽 정리

전산세무 2급 자격증을 준비하려고 하면 가장 먼저 궁금한 것이 있습니다.

"전산세무 2급 시험은 어떻게 출제될까?"

"이론시험과 실무시험은 어떻게 나뉘어 있을까?"

"몇 점을 받아야 합격할 수 있을까?"

"회계 공부를 먼저 해야 할까, 세법 공부를 먼저 해야 할까?"

전산세무 2급은 단순히 회계 이론만 공부해서 합격하는 시험이 아닙니다.

**회계와 세법에 대한 이론을 이해하고 실제 회계 프로그램을 이용해 거래를 입력하는 실무 능력까지 함께 준비해야 하는 시험**입니다.

따라서 시험의 전체 구조를 먼저 이해하고 공부를 시작하면 학습 방향을 잡는 데 도움이 됩니다.

이 글에서는 전산세무 2급을 처음 준비하는 사람을 기준으로 **시험의 기본 구조부터 이론과 실무의 차이, 합격기준, 주요 공부 내용과 시험 준비 시 주의할 점**까지 차근차근 알아보겠습니다.

---

## 1. 전산세무 2급은 어떤 시험일까요?

전산세무 2급은 기업에서 사용하는 회계 및 세무 관련 업무를 수행하는 데 필요한 **회계·세무 지식과 전산 처리 능력**을 평가하는 자격시험입니다.

쉽게 말하면,

> **회계와 세법을 이해하고, 실제 회계 프로그램에서 거래를 처리할 수 있는지를 함께 평가하는 시험**

이라고 이해하면 됩니다.

따라서 전산세무 2급을 준비할 때는 단순히 문제의 정답만 외우는 것보다 다음과 같은 연결 관계를 이해하는 것이 중요합니다.

```text
회계 이론
   ↓
거래의 이해
   ↓
분개
   ↓
회계 프로그램 입력
   ↓
부가가치세 등 세무 처리
   ↓
결산 및 재무제표
```

이러한 흐름을 이해하면 각각의 단원을 따로 공부하는 것보다 시험 전체 구조를 파악하기 쉽습니다.

---

## 2. 전산세무 2급 시험은 크게 이론과 실무로 구성됩니다

전산세무 2급은 크게 보면 **이론적인 지식을 평가하는 부분과 실제 전산 프로그램을 이용하는 실무 부분**으로 나누어 생각할 수 있습니다.

![전산세무 2급 시험 구성](img_computer_tax_level2_exam_structure.svg)

```text
                전산세무 2급
                     │
          ┌──────────┴──────────┐
          │                     │
       이론시험               실무시험
          │                     │
    ┌─────┴─────┐        ┌──────┴──────┐
    │           │        │             │
   재무회계    세법      회계처리     세무처리
    │           │        │             │
  회계원리    부가세    전표입력      부가세
  결산        소득세    결산          원천징수
  재무제표              재무제표      세무자료
```

즉, 전산세무 2급에서는 **이론과 실무를 따로 공부하면서도 서로 연결해서 이해하는 것이 중요합니다.**

예를 들어 이론에서 다음과 같은 분개를 공부했다고 가정해 보겠습니다.

```text
차변 : 소모품비
대변 : 현금
```

실무에서는 단순히 이 분개를 알고 있는 것에서 끝나는 것이 아니라 실제 회계 프로그램에서 거래일자, 거래처, 계정과목, 금액 등을 입력해야 합니다.

---

# 3. 전산세무 2급에서 공부해야 할 주요 영역

전산세무 2급을 공부할 때는 크게 다음과 같은 영역으로 나누어 생각하면 편리합니다.

| 영역       | 주요 학습 내용                              |
| ---------- | ------------------------------------------- |
| 재무회계   | 회계원리, 계정과목, 분개, 결산, 재무제표    |
| 부가가치세 | 과세·면세, 세금계산서, 매입세액, 매출세액   |
| 소득세     | 소득의 종류, 근로소득, 원천징수             |
| 전산회계   | 일반전표, 매입매출전표, 결산자료 입력       |
| 전산세무   | 부가가치세 신고 관련 자료 입력 및 세무 처리 |
| 실무       | 실제 프로그램을 이용한 거래 처리            |

이 중에서도 **회계와 부가가치세는 실무와 연결되는 부분이 많기 때문에 기본 개념을 확실하게 이해하는 것이 중요합니다.**

---

# 4. 재무회계에서는 무엇을 공부할까요?

재무회계는 전산세무 2급의 기초가 되는 영역입니다.

회계를 처음 공부한다면 가장 먼저 **차변과 대변, 자산·부채·자본·수익·비용**의 관계부터 이해해야 합니다.

## 4-1. 회계의 기본 구조

회계에서 가장 기본적인 요소는 다음과 같습니다.

| 구분 | 의미                             | 예시                       |
| ---- | -------------------------------- | -------------------------- |
| 자산 | 기업이 보유하고 있는 경제적 자원 | 현금, 보통예금, 상품, 차량 |
| 부채 | 기업이 갚아야 할 의무            | 외상매입금, 차입금         |
| 자본 | 기업의 순자산                    | 자본금                     |
| 수익 | 기업의 경제적 이익 증가          | 상품매출, 이자수익         |
| 비용 | 수익을 얻기 위해 발생한 지출     | 급여, 임차료, 소모품비     |

회계의 기본적인 관계는 다음과 같습니다.

```text
자산 = 부채 + 자본
```

이 관계는 재무상태표를 이해하는 기본 공식입니다.

---

## 4-2. 차변과 대변

회계에서 초보자가 가장 어려워하는 부분 중 하나가 차변과 대변입니다.

차변과 대변은 단순히 "왼쪽과 오른쪽"이라고 이해하는 것보다 **각 계정의 증가와 감소 관계**를 이해하는 것이 중요합니다.

| 계정 | 증가 | 감소 |
| ---- | ---- | ---- |
| 자산 | 차변 | 대변 |
| 부채 | 대변 | 차변 |
| 자본 | 대변 | 차변 |
| 수익 | 대변 | 차변 |
| 비용 | 차변 | 대변 |

예를 들어 회사가 현금 100,000원을 지급하고 사무용품을 구입했다고 가정해 보겠습니다.

```text
차변 : 소모품비 100,000
대변 : 현금     100,000
```

현금이라는 자산은 감소하므로 대변에 기록하고, 소모품비라는 비용은 증가하므로 차변에 기록합니다.

---

# 5. 전산세무 2급에서 분개가 중요한 이유

전산세무 2급 실무를 공부할 때 **분개 능력은 매우 중요합니다.**

실제 전산 프로그램에 거래를 입력할 때도 결국 거래의 내용을 계정과목으로 바꾸어 입력해야 하기 때문입니다.

예를 들어 다음과 같은 거래가 있다고 해보겠습니다.

> 회사가 상품을 1,000,000원에 외상으로 매입하였다.

이를 회계적으로 표현하면 다음과 같습니다.

```text
차변 : 상품       1,000,000
대변 : 외상매입금 1,000,000
```

즉,

```text
거래 발생
   ↓
거래 내용 파악
   ↓
계정과목 결정
   ↓
차변·대변 결정
   ↓
분개
   ↓
전산 프로그램 입력
```

이라는 흐름으로 연결됩니다.

---

# 6. 부가가치세는 전산세무 2급의 중요한 영역입니다

전산세무 2급을 준비하면서 많은 수험생이 어려워하는 부분이 **부가가치세**입니다.

부가가치세는 단순한 세법 이론뿐만 아니라 실제 매입매출전표 입력과도 연결됩니다.

따라서 부가가치세를 공부할 때는 다음 내용을 서로 연결해서 이해하는 것이 좋습니다.

![부가가치세 학습 구조](img_computer_tax_vat_structure.svg)

```text
부가가치세
    │
    ├── 과세대상
    │
    ├── 과세기간
    │
    ├── 세금계산서
    │
    ├── 매출세액
    │
    ├── 매입세액
    │
    ├── 매입세액 불공제
    │
    ├── 과세·면세
    │
    └── 부가가치세 신고
```

특히 실무에서는 매입매출전표의 부가세 유형을 잘못 선택하면 이후 세무자료에도 영향을 줄 수 있기 때문에 **거래의 성격을 정확하게 파악하는 능력**이 중요합니다.

---

# 7. 매출세액과 매입세액은 무엇일까요?

부가가치세를 이해하려면 먼저 매출세액과 매입세액을 구분해야 합니다.

## 매출세액

사업자가 재화나 용역을 공급하면서 거래상대방에게 받은 부가가치세를 의미합니다.

예를 들어 공급가액이 1,000,000원이고 부가가치세가 100,000원이라면,

```text
공급가액 : 1,000,000원
부가세   :   100,000원
합계     : 1,100,000원
```

이때 100,000원이 매출세액에 해당합니다.

## 매입세액

사업자가 사업과 관련하여 재화나 용역을 구입하면서 부담한 부가가치세입니다.

일반적으로 부가가치세 신고에서는 매출세액에서 공제 가능한 매입세액을 차감하여 납부세액을 계산합니다.

기본적인 구조는 다음과 같습니다.

```text
매출세액
   -
공제 가능한 매입세액
   =
납부세액
```

다만 모든 매입세액이 자동으로 공제되는 것은 아닙니다.

따라서 **매입세액 공제 여부를 판단하는 능력**이 중요합니다.

---

# 8. 매입세액 불공제도 반드시 알아야 합니다

부가가치세를 공부할 때 단순히 "매입세액은 공제된다"고 외우면 안 됩니다.

세법에서는 일정한 경우 매입세액을 공제하지 않습니다.

대표적으로 시험에서 자주 접하게 되는 내용은 다음과 같습니다.

| 구분                         | 핵심 내용                   |
| ---------------------------- | --------------------------- |
| 사업과 직접 관련이 없는 지출 | 사업 관련성이 없는 경우     |
| 일부 승용자동차 관련 비용    | 일정 요건에 따라 제한       |
| 접대 관련 지출               | 일정한 경우 매입세액 불공제 |
| 면세사업 관련 매입           | 면세사업에 사용되는 경우    |
| 세금계산서 관련 문제         | 적법한 증빙 여부가 중요     |

시험에서는 단순히 계정과목만 보고 판단하는 것이 아니라 **거래의 목적과 증빙, 사업 관련성** 등을 함께 확인해야 합니다.

---

# 9. 소득세에서는 무엇을 공부할까요?

전산세무 2급에서는 소득세와 관련된 기본적인 내용도 공부하게 됩니다.

소득세를 처음 접하면 용어가 많아서 어렵게 느껴질 수 있습니다.

먼저 소득의 종류를 구분하는 것부터 시작하는 것이 좋습니다.

```text
소득세
 │
 ├── 이자소득
 ├── 배당소득
 ├── 사업소득
 ├── 근로소득
 ├── 연금소득
 ├── 기타소득
 └── 퇴직소득
```

특히 실무에서는 **근로소득과 원천징수**가 중요하게 연결됩니다.

---

# 10. 원천징수란 무엇일까요?

원천징수는 소득을 지급하는 사람이 소득을 받는 사람에게 세금을 지급액에서 미리 징수하여 국가에 납부하는 제도입니다.

예를 들어 회사가 근로자에게 급여를 지급할 때 근로소득세 등을 원천징수하는 것이 대표적인 사례입니다.

기본적인 흐름은 다음과 같습니다.

![원천징수 처리 흐름](img_computer_tax_withholding.svg)

```text
소득 발생
   ↓
소득 지급
   ↓
지급자가 세금 원천징수
   ↓
원천징수한 세금 납부
   ↓
관련 신고 및 자료 관리
```

따라서 소득세를 공부할 때는 단순히 세율만 외우기보다 **소득이 발생하고 세금이 계산되어 징수되는 전체 흐름**을 이해하는 것이 중요합니다.

---

# 11. 전산세무 2급 실무에서는 어떤 작업을 할까요?

전산세무 2급의 특징은 실제 회계 프로그램을 이용하여 거래를 처리한다는 것입니다.

대표적인 실무 영역을 정리하면 다음과 같습니다.

| 실무 영역    | 주요 내용                          |
| ------------ | ---------------------------------- |
| 회사등록     | 회사 기본정보 확인 및 등록         |
| 거래처등록   | 거래처 정보 입력                   |
| 일반전표     | 일반적인 회계 거래 입력            |
| 매입매출전표 | 매입·매출 거래 입력                |
| 결산         | 결산 관련 자료 입력                |
| 부가가치세   | 부가세 관련 자료 처리              |
| 원천징수     | 근로소득 등 원천징수 관련 처리     |
| 재무제표     | 입력 결과를 바탕으로 재무제표 확인 |

여기서 중요한 점은 각각의 메뉴를 따로 외우는 것이 아닙니다.

**거래를 이해하고 → 분개하고 → 프로그램에 입력하는 과정**을 익혀야 합니다.

---

# 12. 일반전표와 매입매출전표의 차이

전산 프로그램을 처음 사용하는 수험생이 자주 헷갈리는 부분입니다.

## 일반전표

부가가치세와 직접적으로 연결되지 않는 일반적인 회계 거래 등을 입력하는 데 사용됩니다.

예를 들어 급여 지급, 일반적인 비용 지급 등의 거래가 있을 수 있습니다.

## 매입매출전표

상품이나 제품 등을 매입하거나 매출하는 거래처럼 부가가치세와 관련된 거래를 처리할 때 사용되는 경우가 많습니다.

예를 들어 과세 매출 거래가 발생했다고 가정해 보겠습니다.

```text
공급가액 : 1,000,000원
부가세   :   100,000원
합계     : 1,100,000원
```

이 거래는 단순히 매출액만 입력하는 것이 아니라 **공급가액과 부가가치세를 구분하여 처리하는 것**이 중요합니다.

# 13. 결산도 중요합니다

전산세무 2급에서는 결산과 관련된 내용도 중요합니다.

기업은 1년 동안 발생한 거래를 모두 입력했다고 해서 회계처리가 끝나는 것이 아닙니다.

회계기간이 끝나면 결산 절차를 통해 수익과 비용을 적절한 기간에 배분하고 자산과 부채 등을 확인해야 합니다.

대표적으로 공부하게 되는 결산 관련 내용에는 다음과 같은 항목들이 있습니다.

| 결산 항목  | 주요 내용                                     |
| ---------- | --------------------------------------------- |
| 감가상각   | 유형자산의 가치 감소를 비용으로 반영          |
| 대손충당금 | 매출채권 등의 회수 가능성을 고려              |
| 미수수익   | 아직 받지 못했지만 당기에 발생한 수익         |
| 미지급비용 | 아직 지급하지 않았지만 당기에 발생한 비용     |
| 선급비용   | 미리 지급한 비용 중 차기 이후에 해당하는 부분 |
| 선수수익   | 미리 받은 금액 중 차기 이후에 해당하는 부분   |
| 재고자산   | 기말 재고자산을 반영하여 매출원가 등을 계산   |

결산은 재무제표와 직접 연결되기 때문에 단순한 암기보다 **왜 결산분개를 하는지**를 이해하는 것이 중요합니다.

# 14. 전산세무 2급에서 이론과 실무를 연결해서 공부하는 방법

전산세무 2급은 이론과 실무를 완전히 분리해서 공부하면 효율이 떨어질 수 있습니다.

예를 들어 다음과 같은 거래를 생각해 보겠습니다.

> 회사가 상품을 2,000,000원에 외상으로 매입하였다. 부가가치세는 200,000원이다.

먼저 회계적으로 거래를 분석합니다.

```text
상품 증가
매입세액 증가
외상매입금 증가
```

그리고 분개합니다.

```text
차변 : 상품        2,000,000
차변 : 부가세대급금   200,000
대변 : 외상매입금   2,200,000
```

그다음 실제 전산 프로그램에 해당 거래를 입력합니다.

즉,

```text
문제 읽기
   ↓
거래 분석
   ↓
계정과목 판단
   ↓
부가세 여부 판단
   ↓
차변·대변 결정
   ↓
분개
   ↓
전산 입력
```

이 과정을 반복하면 이론과 실무가 서로 연결됩니다.

# 15. 전산세무 2급 공부에서 자주 발생하는 실수

전산세무 2급을 준비할 때 다음과 같은 실수가 자주 발생합니다.

## ① 계정과목을 정확하게 구분하지 못하는 경우

비슷한 성격의 계정과목이 많기 때문에 거래의 내용을 정확하게 읽어야 합니다.

예를 들어 단순히 "돈을 지급했다"는 것만 보고 현금이나 보통예금의 감소만 생각하면 안 됩니다.

**무엇을 위해 지급했는지**를 확인해야 합니다.

---

## ② 차변과 대변을 암기만 하는 경우

차변·대변을 단순 암기하면 조금만 거래가 복잡해져도 어려워질 수 있습니다.

다음처럼 계정의 성격을 먼저 파악하는 것이 좋습니다.

```text
자산 → 증가 차변 / 감소 대변

부채 → 증가 대변 / 감소 차변

자본 → 증가 대변 / 감소 차변

수익 → 증가 대변 / 감소 차변

비용 → 증가 차변 / 감소 대변
```

---

## ③ 부가세 유형을 제대로 확인하지 않는 경우

매입매출전표에서는 거래의 부가가치세 과세 여부와 증빙 등을 함께 확인해야 합니다.

따라서 거래 내용을 읽으면서 다음 사항을 확인하는 습관이 중요합니다.

```text
① 매출인가?
② 매입인가?
③ 과세인가?
④ 면세인가?
⑤ 영세율인가?
⑥ 세금계산서인가?
⑦ 신용카드인가?
⑧ 적격증빙이 있는가?
⑨ 매입세액 공제가 가능한가?
```

---

## ④ 이론만 공부하고 프로그램 연습을 미루는 경우

전산세무는 실제 프로그램을 사용하는 시험이기 때문에 프로그램 조작에 익숙해지는 과정도 필요합니다.

문제를 보고 정답을 알고 있어도 프로그램에서 입력 순서를 모르면 시간이 오래 걸릴 수 있습니다.

따라서 공부할 때는 가능하면 다음과 같이 연결하는 것이 좋습니다.

```text
이론 공부
   ↓
예제 분개
   ↓
전산 프로그램 입력
   ↓
결과 확인
   ↓
틀린 부분 분석
```

# 16. 전산세무 2급에서 중요한 것은 속도보다 정확성입니다

실무시험에서는 제한된 시간 안에 여러 문제를 처리해야 하기 때문에 속도도 중요합니다.

하지만 처음부터 무조건 빠르게 입력하려고 하면 실수가 증가할 수 있습니다.

특히 다음과 같은 오류에 주의해야 합니다.

| 실수 유형        | 발생할 수 있는 문제                 |
| ---------------- | ----------------------------------- |
| 날짜 오류        | 거래가 잘못된 기간에 입력됨         |
| 계정과목 오류    | 재무제표에 잘못 반영                |
| 금액 오류        | 회계자료 전체에 영향을 줄 수 있음   |
| 거래처 오류      | 거래처별 자료가 잘못 집계될 수 있음 |
| 부가세 유형 오류 | 부가세 신고자료에 영향을 줄 수 있음 |
| 차변·대변 오류   | 분개 자체가 잘못됨                  |
| 누락             | 해당 거래가 장부에 반영되지 않음    |

따라서 처음에는 정확하게 입력하는 연습을 하고, 반복하면서 자연스럽게 입력 속도를 높이는 것이 중요합니다.

# 18. 기출문제를 풀 때는 정답보다 풀이 과정을 확인해야 합니다

기출문제를 공부할 때 단순히 정답을 맞혔는지만 확인하면 실력이 충분히 쌓이지 않을 수 있습니다.

예를 들어 다음과 같은 문제가 있다고 해보겠습니다.

> 상품을 현금으로 구입하였다.

정답을 맞혔다면 그다음에는 다음 내용을 스스로 확인해 보는 것이 좋습니다.

```text
상품은 어떤 계정과목인가?
        ↓
상품은 자산인가?
        ↓
상품이 증가했으므로 차변인가?
        ↓
현금은 자산인가?
        ↓
현금이 감소했으므로 대변인가?
```

결국,

```text
차변 : 상품
대변 : 현금
```

이라는 결과가 나옵니다.

이처럼 **정답을 외우는 것이 아니라 정답이 나오는 과정을 이해하는 것**이 중요합니다.

# 22. 시험 준비에서 가장 중요한 것은 회계와 세무의 연결입니다

전산세무 2급은 단순한 회계시험도 아니고 단순한 세법시험도 아닙니다.

**회계 지식을 바탕으로 실제 거래를 처리하고, 그 거래에 적용되는 세법까지 함께 이해하는 것이 핵심입니다.**

예를 들어 상품을 판매했다면 단순히 매출이 발생했다고 끝나는 것이 아닙니다.

```text
상품 판매
   ↓
매출 발생
   ↓
회계 분개
   ↓
부가가치세 발생 여부 확인
   ↓
매출세액 처리
   ↓
전산 프로그램 입력
   ↓
관련 신고자료 반영
```

하나의 거래가 회계와 세무, 전산실무로 연결됩니다.

이러한 구조를 이해하면 각각의 문제를 따로 외우는 부담을 줄일 수 있습니다.

# 마무리

전산세무 2급은 처음 접하면 회계와 세법, 전산 프로그램을 동시에 공부해야 하기 때문에 어렵게 느껴질 수 있습니다.

하지만 전체 구조를 살펴보면 핵심은 비교적 명확합니다.

> **회계의 기본 원리를 이해하고 → 거래를 분개하고 → 전산 프로그램에 입력하고 → 부가가치세와 소득세 등 세무처리를 연결하는 것**

입니다.

특히 처음 공부할 때는 다음과 같은 순서를 기억하면 전체적인 학습 구조를 파악하기 쉽습니다.

```text
회계 기본
   ↓
계정과목
   ↓
분개
   ↓
전표입력
   ↓
매입·매출
   ↓
부가가치세
   ↓
결산
   ↓
소득세·원천징수
   ↓
기출문제
   ↓
실무 반복
```

전산세무 2급은 단순히 암기한 내용을 선택하는 시험이 아니라 **거래를 이해하고 회계처리와 세무처리를 실제로 적용하는 능력**이 중요한 시험입니다.

따라서 공부할 때도 각각의 단원을 따로 외우기보다는 **하나의 거래가 회계처리와 세무처리, 전산입력으로 어떻게 연결되는지**를 중심으로 이해하는 것이 중요합니다.
