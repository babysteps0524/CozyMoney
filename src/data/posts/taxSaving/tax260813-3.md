# 연금저축·IRP 세액공제, 최대 148만원 돌려받는 법

직장인 절세 상품 중 가장 먼저 언급되는 두 가지가 있습니다.

바로 **연금저축**과 **IRP(개인형퇴직연금)**입니다.

---

## 1. 연금저축과 IRP는 무엇인가요?

두 상품 모두 **노후 자금을 위해 돈을 넣으면, 넣은 만큼 세금을 깎아주는**

계좌라고 생각하시면 됩니다.

- **연금저축**: 증권사·보험사 등에서 자유롭게 가입하는 개인연금
- **IRP**: 퇴직금을 받는 통로이자, 추가 납입도 가능한 퇴직연금 계좌

두 계좌는 **세액공제 한도를 공유**하는 구조로 운영됩니다.

---

## 2. 세액공제 한도는 얼마일까요?

| 구분              |         한도 |
| ----------------- | -----------: |
| 연금저축 단독     |       600만원 |
| 연금저축 + IRP 합산 |       900만원 |

가장 널리 쓰이는 조합은 **연금저축 600만원 + IRP 300만원 = 900만원**입니다.

---

## 3. 공제율은 소득에 따라 다릅니다

| 총급여 기준        | 공제율 | 900만원 납입 시 환급액 |
| ------------------- | -----: | ----------------------: |
| 5,500만원 이하      |  16.5% |               148만 5천원 |
| 5,500만원 초과      |  13.2% |               118만 8천원 |

예를 들어 총급여 5,000만 원인 직장인이 900만 원을 꽉 채워 넣었다면,

$$
900만원 \times 16.5\% = 148만 5천원
$$

이 금액만큼 세금을 돌려받게 됩니다.

---

## 4. 주의할 점

연금저축이나 IRP는 **55세 이전에 중도 해지**하면,

그동안 세액공제 받은 금액과 운용 수익 전체에

**기타소득세 16.5%**가 부과됩니다.

즉, 돌려받았던 세금을 사실상 다시 반납하는 셈이므로,

가입 전에 **장기간 유지할 수 있는 여유 자금**인지 꼭 확인해야 합니다.

## 한눈에 정리해 보겠습니다

| 용어         | 의미                                       |
| ------------ | ------------------------------------------ |
| 연금저축     | 개인이 자유롭게 가입하는 절세형 개인연금   |
| IRP          | 퇴직금 수령 및 추가 납입이 가능한 퇴직연금 |
| 세액공제 한도 | 연금저축·IRP 합산 연 900만원               |
| 중도해지     | 기타소득세 16.5% 부과, 환급액 사실상 반납  |

---

## 마무리

연금저축과 IRP는 **"노후 준비 + 세금 환급"**을 동시에 잡을 수 있는

대표적인 절세 상품입니다.

다만 중도해지 페널티가 크기 때문에, 여유 자금으로 장기 계획을 세워

가입하는 것이 중요합니다.
