# 신용카드 소득공제, 왜 나는 혜택이 없을까?

"카드 많이 썼는데 왜 공제가 별로 없지?"

연말정산 때 가장 많이 나오는 불만 중 하나입니다.

이 궁금증을 풀어드리겠습니다.

---

## 1. 총급여의 25%부터 시작됩니다

신용카드 소득공제는 **쓴 만큼 다 공제해 주는 것이 아닙니다.**

**총급여의 25%를 초과한 금액**부터 공제 대상이 됩니다.

예를 들어 총급여 4,000만원인 직장인이라면,

$$
4,000만원 \times 25\% = 1,000만원
$$

즉, 1년에 1,000만원을 쓸 때까지는 공제 대상이 아니고,

**1,000만원을 초과한 부분부터** 공제가 시작됩니다.

---

## 2. 결제수단마다 공제율이 다릅니다

| 결제수단             | 공제율 |
| -------------------- | -----: |
| 신용카드              |    15% |
| 체크카드, 현금영수증  |    30% |
| 전통시장, 대중교통    |    40% |

즉, 25%를 초과한 구간에서는 **체크카드나 현금영수증이 신용카드보다**

**두 배의 공제율**을 받습니다.

---

## 3. 예시로 계산해 보겠습니다

총급여 4,000만원(기준 1,000만원)인 사람이 2,000만원을 모두

**신용카드로만** 썼다고 가정해 보겠습니다.

| 구분           |     금액 |
| -------------- | -------: |
| 총 사용액      |   2,000만원 |
| 기준 초과분    |   1,000만원 |
| 공제율         |      15% |
| 소득공제액     |    150만원 |

만약 초과분 1,000만원을 체크카드로 썼다면,

$$
1,000만원 \times 30\% = 300만원
$$

같은 금액을 써도 공제액이 두 배로 늘어납니다.

---

## 4. 공제 한도도 있습니다

기본 한도는 **300만원**이며, 총급여 7,000만원 이하이면서

자녀가 2명 이상인 가구는 한도가 **최대 400만원**까지 늘어납니다.

여기에 전통시장·대중교통 사용분은 각각 **100만원씩 추가 한도**가

별도로 적용됩니다.

## 한눈에 정리해 보겠습니다

| 용어         | 의미                                   |
| ------------ | --------------------------------------- |
| 최저사용금액 | 총급여의 25%, 이 금액까지는 공제 없음  |
| 신용카드     | 초과분에 대해 15% 공제                 |
| 체크카드·현금영수증 | 초과분에 대해 30% 공제           |
| 전통시장·대중교통 | 초과분에 대해 40% 공제, 추가 한도  |

---

## 마무리

**총급여의 25%까지는 어떤 카드를 쓰든 공제에 영향이 없습니다.**

그 구간까지는 혜택이 좋은 신용카드를 쓰고, 25%를 넘긴 이후부터는

체크카드나 현금영수증으로 바꾸는 전략이 절세에 유리합니다.
